# Phase 2 — UI Design Contract

> Visual and interaction contract for the eframe/egui 0.36.1 timestamp window. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> This is a native tool window, not a web/shadcn app. Chrome here is the template Phase 3 clones for JSON and translate (UI-02). CONTEXT.md is locked.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none |
| Icon library | none — text labels only; no icon-only actions |
| Font | egui 0.36.1 built-ins: Ubuntu (proportional labels/buttons) + Hack (monospace field values) |

**Stack (locked):** eframe 0.36.1 + egui 0.36.1. Shared look comes from `xtools-ui` tokens plus `apply_theme` / chrome widgets compiled into the tool. No CSS. No Tailwind. No shadcn. No Radix. No web fonts.

**Token source:** `crates/xtools-ui/src/theme.rs`. Host already paints orbs from `ORB_FILL` / `ORB_MARK` / `MARK_PX`. This phase maps those same numbers onto egui `Visuals` so the window reads as one suite with the host orb.

**Widget home:** chrome lives in `xtools-ui` (`apply_theme`, title area, labeled field, copy button, inline error). `xtools-time` does not invent a second look.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline error gap under a field; field/button corner radius |
| sm | 8px | Label → field; field → 「复制」; 「现在」 → datetime label |
| md | 16px | Gap between the three field groups; title strip → first group |
| lg | 24px | CentralPanel content padding on all sides |
| xl | 32px | Control height (TextEdit + buttons); title-strip content height |
| 2xl | 48px | Unused this phase |
| 3xl | 64px | 「复制」 / 「现在」 minimum width |

Exceptions: none

**Window size is not a spacing token.** Default inner size is 560×480 logical px (D-14). Minimum inner size 480×360. `persist_window: false`.

## Typography

Exactly three sizes, two weights. Body size matches host `MARK_PX` (16.0).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 12px | 400 | 1.4 |
| Heading | 20px | 600 | 1.2 |
| Display | 20px | 600 | 1.2 |

Display is not a larger hero size — this form has no hero numeral. Heading and Display share 20px / 600 so the scale stays 12 / 16 / 20.

| Surface | Role | Notes |
|---------|------|-------|
| In-content title `时间戳` | Heading | Left of the title strip |
| Field captions `秒` / `毫秒` / `本地时间` | Label | Muted mark color |
| Field values | Body | Monospace (Hack) |
| 「复制」 / 「现在」 / 「已复制」 | Body | Proportional (Ubuntu) |
| Inline error | Body | Destructive color, still 16px / 400 / 1.5 |
| Native title bar `xtools · 时间戳` | compositor font | Do not restyle OS chrome |

Do not add a third weight. Host orb marks are cairo Bold; tool chrome stays 400 + 600.

## Color

Hex is the nearest 8-bit mapping of `theme.rs` floats. Implementers read `Color` tokens and convert; do not scatter raw hex in `xtools-time`.

| Token | Float (`theme.rs`) | Hex |
|-------|--------------------|-----|
| `ORB_FILL` | `(0.12, 0.12, 0.14, 1.0)` | `#1F1F24` |
| `ORB_MARK` | `(0.92, 0.93, 0.95, 1.0)` | `#EBEDF2` |

`#EBEBEF` is the same light-mark family as a rough reading of `ORB_MARK`. The contract hex is `#EBEDF2`.

Secondary is `ORB_FILL` lifted by `0.06` on each channel — still the orb-disk family, not a new hue.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#1F1F24` (`ORB_FILL`) | Window fill, CentralPanel, chrome ground |
| Secondary (30%) | `#2E2E33` | Title strip, field wells, idle non-accent button fill |
| Accent (10%) | `#EBEDF2` (`ORB_MARK`) | Fill of enabled 「复制」 and 「现在」 only |
| Destructive | `#C45C5C` | Inline parse-error text only |

Accent reserved for: enabled 「复制秒」 button, enabled 「复制毫秒」 button, 「现在」 button.

Not accent: field borders, text cursor, focus ring, scrollbars, window decorations, idle/disabled buttons, labels, title text.

| Derived | Value | Usage |
|---------|-------|-------|
| On-accent text | `#1F1F24` | Glyphs on 「复制」 / 「现在」 |
| Body / title text | `#EBEDF2` | Heading and field values |
| Muted label | `#8F8F94` | Captions; `ORB_MARK` at 0.55 over `ORB_FILL` (same 0.55 the host already uses on the orb ring) |
| Field focus ring | `#8F8F94` 1px | Not accent |
| Idle button fill | `#2E2E33` | Disabled 「复制」 when that field is empty |
| Idle button text | `#8F8F94` | Disabled 「复制」 |

No second decorative accent. Destructive is semantic error text, never a button fill. No colored wash behind the whole form.

| Element | Copy |
|---------|------|
| Native window title | `xtools · 时间戳` |

| Field caption — datetime | `本地时间` |

| Now action (D-11) | `现在` — writes the current instant into all three fields |
| Copy success | `已复制` — replaces that button’s `复制` for 1s, then reverts. No toast. |

First open is not an empty page (D-09): all three fields start filled from now. Empty/error copy applies only after the user clears or breaks a field.

## Layout

Vertical stack. Two timestamp boxes on top, one local datetime below (D-05, D-06, D-07). No UTC row. No RFC3339 editor. No custom format field.

```
┌─ xtools · 时间戳 ──────────────────────────────────┐
│  24px pad                                          │
│  时间戳                                            │
│                                                    │
│  秒                                                │
│  ┌──────────────────────────────┐  ┌────┐          │
│  │ 1710000000                   │  │复制│          │
│  └──────────────────────────────┘  └────┘          │
│  [inline error if this field is the broken one]    │
│                                                    │
│  毫秒                                              │
│  ┌──────────────────────────────┐  ┌────┐          │
│  │ 1710000000000                │  │复制│          │
│  └──────────────────────────────┘  └────┘          │
│  [inline error if this field is the broken one]    │
│                                                    │
│  本地时间                               ┌────┐     │
│  ┌──────────────────────────────────┐   │现在│     │
│  │ 2026-03-09 20:00:00.000          │   └────┘     │
│  └──────────────────────────────────┘              │
│  [inline error if this field is the broken one]    │
│                                                    │
└────────────────────────────────────────────────────┘
```

**「现在」 sits on the datetime label row**, trailing the caption — beside datetime, not beside the timestamp boxes (D-11).

**「复制」 sits only on the seconds row and the milliseconds row** (D-08, D-12). No copy control on datetime.

| Region | Spec |
|--------|------|
| Title strip | Height 32px. Heading `时间戳` left-aligned in `#EBEDF2`. No extra buttons. 16px below to the first group |
| Seconds group | Caption `秒`. One-line `TextEdit` (monospace) grows; 「复制」 64×32 on the right, 8px gap |
| Milliseconds group | Same rhythm as seconds. Caption `毫秒` |
| Datetime group | Caption `本地时间` + 「现在」 64×32 on that same row. Full-width `TextEdit` under it. No copy button |
| Group gap | 16px |
| Error | One 16px body line, 4px under the edited field only. Do not banner the window |

**Focal point:** the seconds value field (top of the stack, daily log/API use). Visual order: seconds field → milliseconds field → datetime field → accent buttons.

**Hierarchy:** field values (body, mark color, monospace) outrank captions (label, muted). Accent buttons are the only light-filled controls.

## Interaction & States

### Open / focus

| Event | Fields |
|-------|--------|
| First launch, or launch after the process exited | Fill all three from the current instant (D-09) |
| Clock-orb click while this process is live | Focus the existing window. Do not overwrite fields (D-10) |
| 「现在」 | Write the current instant into all three fields. Clear any inline error |

### Convert (TIME-01)

Edit any one field. When that field parses, the other two update immediately. Seconds and milliseconds stay in lockstep (`ms = s × 1000`) (D-06).

| Field | Editable format |
|-------|-----------------|
| 秒 | Integer Unix seconds (usually 10 digits). No thousands separators |
| 毫秒 | Integer Unix milliseconds (usually 13 digits). No thousands separators |
| 本地时间 | Local wall time `YYYY-MM-DD HH:MM:SS.mmm`. No `T`, no `Z`, no offset, no timezone name (D-07) |

`.mmm` is always shown so millisecond precision is visible in the datetime box. There is no second datetime format and no format picker.

### Invalid / empty (discretion)

Do not crash. Keep the last good values in the peer fields. Show the matching error line under the field the user is editing. Leave the broken field’s text as typed so the user can fix it.

| State | Peers | Error | 「复制」 on that row |
|-------|-------|-------|---------------------|
| Valid | Live-update | Hidden | Enabled, accent fill |
| Empty | Last good | Empty-state heading + body | Disabled, secondary fill |
| Invalid parse | Last good | Matching error row | Disabled, secondary fill |

Only one inline error is visible: the field currently being edited, if it is empty or invalid.

### Copy (TIME-02 narrowed)

| Button | Copies |
|--------|--------|
| 「复制」 on 秒 | The exact digits currently in the seconds field (10-digit Unix seconds when valid) |
| 「复制」 on 毫秒 | The exact digits currently in the milliseconds field (13-digit Unix milliseconds when valid) |

Use `ctx.copy_text`. Keep the process alive as clipboard owner. Do not close the window after copy.

Feedback: that button’s label becomes `已复制` for 1s, then `复制` again.

### Out of this chrome

Do not ship:

- RFC3339 copy button
- Custom strftime box or copy
- Datetime copy button
- UTC companion row
- Format dropdown
- Extra “copy all” / “copy as” controls
- Clipboard auto-fill on open
- Persist last values or last window position

Those are CONTEXT deferred ideas. ROADMAP success criterion 4 still names RFC3339/custom; CONTEXT D-12/D-13 narrows TIME-02 for this phase to seconds + milliseconds only.
