## Phase Goal

**As a** Linux desktop user, **I want to** drag an always-on-top main orb and click it to expand or collapse three compile-time function orbs painted from shared theme tokens, **so that** I can park a quiet x on the output and open the timestamp / JSON / translate menu without a query field.

This plan is Slices B and C (HOST-02, HOST-03, LAUNCH-03) on the Plan 01-01 Overlay.

## Artifacts this phase produces

- Fan-above layout of three compile-time function disks (Time / Json / Trans)
- 120 ms tick-callback pop and reverse collapse
- Two-state compositor input region (disk-only vs whole surface)
- Dismiss on main re-click, function-orb click, outside/glass click, and drag-while-open
- Stashed `gdk::Event` on function-orb click (no tool process)

## Prohibitions

- No query field / command palette
- No plugin directory and no directory scan for tools
- No egui/winit host toolkit in `xtools-host`
- No tool windows and no spawn of a tool binary
- No persisted orb position
- Function orbs do not travel with a drag (D-15)
- Hover does not expand or collapse (D-11)
- Do not use GtkTimedAnimation / CallbackAnimationTarget (not in gtk4 0.11.4)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Compositor pointer → host hit-test | Untrusted coordinates decide expand/collapse/stash |
| Expanded Overlay → desktop | Whole-surface input can brick the session if not released on collapse |
| Function-orb click → future spawn | Phase 2 will read last_pointer_event; this phase must not launch a binary or clear env |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-07 | Elevation of privilege | input.rs function-orb click | medium | mitigate | Stash gdk::Event only. Do not spawn, do not env_clear, do not exec a tool path |
| T-01-08 | Information disclosure | last_pointer_event | low | mitigate | Keep the Event in memory; do not log position or time at info/warn |

| T-01-SC | Tampering | no new crates | low | accept | This plan adds no registry packages. Residual: none |
